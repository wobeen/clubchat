# ITDA brand

Logo chosen by the team: friendly speech bubbles gathered around one shared chat bubble, with the ITDA wordmark in navy.
Generated with GPT image generation (OpenAI) and selected by the team; disclosed in the contest AI-use table.
Source is a raster image; these files are cut from it.

| File                                   | Use                                                                  |
| -------------------------------------- | -------------------------------------------------------------------- |
| `itda-logo.png`                        | Horizontal lockup (mark + ITDA), transparent background, 800 px wide |
| `itda-mark.png`                        | Mark only, transparent, 256 px square: app rail                      |
| `itda-icon-192.png`, `itda-icon-512.png` | App icons (manifest), mark on a white tile                         |
| `../favicon.png`                       | Browser tab icon, 64 px                                              |

Colours taken from the logo and used as the app accent (`public/white-theme.css`):
navy `#023086` (wordmark), royal `#0045de` (`--accent-700`), bright `#127bfe` (`--accent-500`), light `#a6d1fe` (`--accent-300`).

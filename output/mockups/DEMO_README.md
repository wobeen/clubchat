# ITDA 단일 HTML 데모

`itda-full-demo.html`을 일반 브라우저에서 열면 실행된다. 설치·서버·네트워크 연결이 필요 없다. 앱과 별도 저장 키를 쓰며 실제 계정·초대·다기기 동기화는 연결하지 않는다.

체험 순서:
1. 내 소속 선택 → 새 캡슐 생성.
2. 연습 대화 넣기 → 필요 메시지와 담당자를 선택해 하위 캡슐 위임.
3. 하위 캡슐 열기 → 대화 넣기 → 초안 → 확인. 여러 담당자면 시연 멤버를 바꾸거나 명시적인 연습 동료 확인 버튼 사용.
4. 상위로 돌아오기 → 초안 검토 → 공동 확인.
5. 확정 일정과 다음 캡슐에서 미결 승계 확인.

추가 동작: 소속 생성, 연습 초대 코드 `ITDA2026`으로 가입, 멤버 전환, 필터, 초안 수정/근거/버전 복원, 미결 상태/승계 대상, 불참/탈퇴/진행자 변경, 하위 보류/취소, 확정 정정, ICS 내보내기, 기록 텍스트, JSON 내보내기/불러오기, 데모 초기화.

HTML 뷰어가 스크립트를 차단하면 파일을 다운로드해 Chrome/Edge 등에서 연다. 저장 차단 환경에서도 현재 화면에서 체험 가능하며 새로고침 지속은 보장하지 않는다. 초기화는 이 데모의 자료만 교체한다.

빌드: `node scripts/build-html-demo.mjs`. 현재 도메인 코드와 `full-demo-ui.js`를 HTML 안에 포함한다. 앱 코드를 변경하지 않는다.
